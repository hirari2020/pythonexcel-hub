情報は2026年8月時点のものです。アイコンは各サービス公式ロゴを参照しています。
※モデルは量子化（GGUF形式など）を前提とすれば、より少ないメモリでも動作します。OllamaやLM Studioからは量子化済みモデルをそのままダウンロードできます。
※tsuzumi はオープンウェイトではなく、商用ライセンス契約によるオンプレミス導入形式です。
※月間100万トークン以上使う場合は、クラウドAPIよりローカル運用の方がコストを抑えられるケースがあります。
※GLM-5.3 / Kimi K3（2.8T）/ Qwen3.8-Max（2.4T）/ MiniMax M3 / Hunyuan Hy3 などの数百B〜T級オープンモデルは家庭用PCでは動かせず、サーバー・クラウドでの自社運用向けです。ローカルでは27B以下や蒸留・量子化版を利用します。また最新の旗艦オープンモデルは、MIT / Apache ではなく専用ライセンス（GLM-5.3 License・Qwen3.8-Max License など）で公開される傾向が出ています。
※ Ornith-1.5（MIT・2026年8月19日公開）の開発元 DeepReinforce は米国サンタクララ拠点ですが、創業者は中国出身の著名NLP研究者です。「Claude Opus 4.8 同等」等の性能値は現時点でベンダー自己申告のため、注記付きで掲載しています。
※Perplexity Portable Computer は、検索AIのPerplexityがNVIDIAと提携して2026年8月25日に公開したローカル実行型エージェントです（データを外部送信せず、ローカル処理はトークン課金なし）。Pro以上の契約者向けで、VRAM 24GB以上の NVIDIA RTX GPU（RTX 3090以降のハイエンド級）または NVIDIA DGX Spark が必要です。一般的なノートPCやGPU非搭載のパソコンでは動作しません。Windows対応は2026年9月予定です。
★ は中国企業（Alibaba・DeepSeek・Z.ai・Moonshot・MiniMax・Tencent）が開発したモデル、または中国系モデルをベースに追加学習した国産モデルです（ELYZAの主力はQwenベース、qwq-bakeneko は QwQ ベース。Swallow は Llamaベース、tsuzumi は完全国産）。ローカル実行なのでデータが外部送信されることはありませんが、組織のポリシーによっては採用可否をご確認ください。
● は純国産（フルスクラッチ開発）のモデル、€ は欧州企業開発のモデルです。Swallow は日本開発ですが Llama（米Meta）ベースのため ● を付けていません。同様に中国系モデルをベースにした国産モデル（ELYZA・qwq-bakeneko）には ★ を付けています。
